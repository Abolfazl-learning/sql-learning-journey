# SQL Basics

## What is SQL?
SQL is used to work with relational databases.

## SELECT
Used to retrieve data from a table.

Example:
SELECT * FROM customers;

## WHERE
Used to filter rows.

Example:
SELECT * FROM customers
WHERE age > 25;
